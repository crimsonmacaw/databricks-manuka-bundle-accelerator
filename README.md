# Databricks Bundle Accelerator

This repo allows users to rapidly deploy onto Databricks platform using CI/CD and Databricks Asset Bundles. It enables a Data AI team to get up and running with the following:

- Ingestion Patterns
- Lakeflow Declarative Pipelines
- Testing
- ML Ops
- Databricks Apps
- Cost Monitoring Dashboard
- Permissions Setting

To learn more, see:
* The launch blog post at https://www.databricks.com/blog/announcing-general-availability-databricks-asset-bundles
* The docs at https://docs.databricks.com/dev-tools/bundles/index.html
